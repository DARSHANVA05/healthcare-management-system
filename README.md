# HealthCare Management System
This is a web-based application designed to streamline hospital operations by enhancing administrative, clinical, 
and financial workflows. It supports various user roles such as doctors, patients, laboratory technicians, 
receptionists, and administrators.

# Technologies Used
  - Java, Spring Boot, Spring Data JPA
  - Thymeleaf, MySQL (AWS RDS)
  - AWS Elastic Beanstalk, AWS Load Balancer
  - Maven, Java-Mail
  - Payment Gateway integration
  - Llama ML model integration

# Features
  - Electronic health records for multiple roles (Doctors, Patients, Technicians, Admin)
  - Online appointment booking
  - Medicine composition reference using Llama model
  - Notification to different set of users by mail

#   ️How to Run
  - Clone the repo
  - Set up database credentials in application.properties
  - Set up mail credentials in application.properties
  - Set up Llama model configuration in application.properties
  - Run the application
  - Open the app in browser at http://localhost:9090
